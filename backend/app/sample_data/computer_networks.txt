Computer Networks - Course Notes

Unit 1: Introduction to Computer Networks
A computer network is a collection of interconnected devices that exchange data using agreed rules called protocols. A protocol is a set of rules that governs the format, timing and sequencing of messages exchanged between devices. Network topology refers to the physical or logical arrangement of nodes and links in a network. In a star topology every node connects to a central hub or switch, so a failure of the central device brings down the whole network. In a bus topology all nodes share a single backbone cable, which makes it cheap but hard to troubleshoot. A mesh topology connects every node to every other node, which provides the highest redundancy at the highest cabling cost. A LAN is a network that covers a small geographic area such as a single building or campus. A WAN is a network that spans large geographic distances and typically connects multiple LANs. The OSI model is a seven-layer reference model that standardises the functions of a communication system. The TCP/IP model is a four-layer protocol suite on which the modern Internet is built. Bandwidth is the maximum rate at which data can be transferred over a link, measured in bits per second. Latency is the time taken for a packet to travel from its source to its destination. Throughput is the actual rate of successful data delivery over a link, and it is always less than or equal to the bandwidth.

Unit 2: Physical Layer and Transmission Media
The physical layer is responsible for transmitting raw bits over a communication medium. Twisted pair cable consists of two insulated copper wires twisted together to reduce electromagnetic interference. Coaxial cable has a central copper conductor surrounded by an insulating layer and a metallic shield, giving it better noise immunity than twisted pair. Optical fibre transmits data as pulses of light through a glass core and offers the highest bandwidth with the lowest attenuation. Attenuation is the loss of signal strength as a signal travels through a medium. Modulation is the process of varying a carrier signal in order to encode information onto it. Multiplexing is a technique that allows multiple signals to share a single communication channel. Frequency division multiplexing assigns each signal a different frequency band within the channel. Time division multiplexing gives each signal the entire channel for a short, fixed time slot. The Nyquist theorem states that the maximum data rate of a noiseless channel is twice the bandwidth multiplied by the logarithm of the number of signal levels. The Shannon capacity defines the theoretical maximum data rate of a noisy channel in terms of its bandwidth and signal-to-noise ratio. Circuit switching establishes a dedicated path between sender and receiver for the entire duration of a communication session. Packet switching divides data into packets that are routed independently and share network links with other traffic.

Unit 3: Data Link Layer
The data link layer is responsible for reliable node-to-node delivery of frames over a single link. Framing is the process of dividing the bit stream received from the network layer into manageable units called frames. A parity bit is an extra bit added to a data unit so that the total number of ones becomes even or odd, allowing single-bit errors to be detected. CRC is an error-detection technique that treats the data as a polynomial and appends the remainder of a division by a generator polynomial. Hamming code is an error-correcting code that can detect two-bit errors and correct single-bit errors. Flow control is a mechanism that prevents a fast sender from overwhelming a slow receiver. Stop-and-wait ARQ is a protocol in which the sender transmits one frame and waits for its acknowledgement before sending the next frame. Go-Back-N ARQ is a sliding window protocol in which the receiver discards out-of-order frames and the sender retransmits all frames from the lost one onwards. Selective Repeat ARQ is a sliding window protocol in which only the lost or damaged frames are retransmitted. A MAC address is a 48-bit hardware address that uniquely identifies a network interface on a local network. CSMA/CD is a media access control method used in classic Ethernet in which stations listen before transmitting and stop when a collision is detected. CSMA/CA is a media access control method used in wireless LANs that tries to avoid collisions before they happen. A switch is a data link layer device that forwards frames based on the destination MAC address.

Unit 4: Network Layer
The network layer is responsible for delivering packets from the source host to the destination host across multiple networks. An IP address is a logical address that identifies a host and the network to which it belongs. IPv4 uses 32-bit addresses, whereas IPv6 uses 128-bit addresses to overcome address exhaustion. Subnetting is the practice of dividing a large network into smaller logical networks by borrowing bits from the host portion of the address. A subnet mask is a 32-bit number that separates the network portion of an IP address from the host portion. CIDR is an addressing scheme that replaces fixed address classes with variable-length prefixes for more efficient allocation. Routing is the process of selecting the best path for a packet to travel from source to destination. A router is a network layer device that forwards packets between different networks using its routing table. Distance vector routing is an algorithm in which each router shares its entire routing table with its direct neighbours only. Link state routing is an algorithm in which each router floods information about its directly connected links to all routers in the network. RIP is a distance vector routing protocol that uses hop count as its metric and limits a path to fifteen hops. OSPF is a link state routing protocol that uses the Dijkstra algorithm to compute the shortest path tree. ARP is a protocol that maps a known IP address to its corresponding MAC address. NAT is a technique that translates private IP addresses into a public IP address so that many hosts can share one public address. ICMP is a protocol used by network devices to report errors and send diagnostic messages such as ping.

Unit 5: Transport Layer
The transport layer is responsible for process-to-process delivery of data between applications running on different hosts. A port number is a 16-bit identifier that distinguishes one application process from another on the same host. A socket is the combination of an IP address and a port number that uniquely identifies an endpoint of communication. UDP is a connectionless transport protocol that provides fast, best-effort delivery without acknowledgements or ordering. TCP is a connection-oriented transport protocol that provides reliable, ordered and error-checked delivery of a byte stream. The three-way handshake is the procedure TCP uses to establish a connection by exchanging SYN, SYN-ACK and ACK segments. The sliding window is a mechanism TCP uses for flow control, in which the receiver advertises how many bytes it is willing to accept. Congestion control is a set of techniques that prevents senders from overloading the network with more traffic than it can carry. Slow start is a congestion control phase in which the congestion window doubles every round-trip time until it reaches a threshold. Congestion avoidance is a phase in which the congestion window grows linearly by one segment per round-trip time. Fast retransmit is a technique in which TCP resends a lost segment after receiving three duplicate acknowledgements instead of waiting for a timeout. A checksum is a value computed over a segment that allows the receiver to detect corruption in transit.

Unit 6: Application Layer and Network Security
The application layer is the layer that provides network services directly to user applications. DNS is a distributed naming system that translates human-readable domain names into IP addresses. HTTP is a stateless request-response protocol used to transfer web pages between browsers and web servers. HTTPS is the secure version of HTTP in which the communication is encrypted using TLS. SMTP is a protocol used to send electronic mail from a client to a mail server or between mail servers. FTP is a protocol used to transfer files between a client and a server using separate control and data connections. DHCP is a protocol that automatically assigns IP addresses and other configuration parameters to hosts joining a network. Encryption is the process of converting plaintext into ciphertext so that only authorised parties can read it. Symmetric key cryptography is a scheme in which the same secret key is used for both encryption and decryption. Public key cryptography is a scheme in which a public key encrypts data and a mathematically related private key decrypts it. A digital signature is a cryptographic value that proves the authenticity and integrity of a message. A firewall is a security device that monitors and filters incoming and outgoing network traffic according to predefined rules. A denial-of-service attack is an attempt to make a service unavailable by flooding it with illegitimate requests.
